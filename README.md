# Week on a Plate

A weekly family meal planner: breakfasts, full school lunchboxes, dinners, adult snacks,
recipes, pregnancy-safe options and a Coles/Woolworths shopping list.

- **App:** `index.html` is the whole app. GitHub Pages serves it at
  `https://<your-username>.github.io/week-on-a-plate/`.
- **Shared data:** the app saves your household to `data/household.json` in this repository.
  It creates that file the first time a device connects. Don't edit it by hand while the app is open.
- **Updating the app:** replace `index.html` with a new version. Phones and PCs pick it up next time they open
  the app (allow a few minutes for GitHub Pages to update).

Note: this repository is public, so the household data in `data/household.json` can be seen by anyone who finds it.
